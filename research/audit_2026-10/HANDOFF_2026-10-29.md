## 5. Known limits of the new data (do not oversell)
1. **Warm-up asymmetry:** Kaggle names start 2016-01-01, so no signals before ~mid-2016; survivors have 2014
   warm-up. Delisted names can't be picked in H1-2016 (mild bias toward survivors early). The per-year Kaggle sets
   `mayookhlad/NSE-Cash.Market-Bhavcopies` (2010–2015 listed on a mirror) could fix this — UNVERIFIED contents.
2. **Data ends 2024-12-13** for everything in the file; **2025-26 is absent for the delisted names** (fine for
   names that died earlier; DHANI still trades but is force-exited at 2024-12-13, price 90.27).
3. **245 still-listed names missing from the DB are NOT yet added** (PEL, GNFC, DELTACORP, RIIL, RAIN…). They need
   2025-26 prices (yfinance via `scripts/ingest_external_prices.py`, cross-check against this file with
   `price_validation.compare_sources`). The `full` universe is therefore still partly survivor-biased.
4. Several data-ended names last print before true delisting (JPASSOCIAT last EQ bar 2023-12-29 @19.8; whether it
   kept trading is UNVERIFIED). Engine force-exits at last close ± slippage (`engine.py:120-200`); mergers
   (GRUH→Bandhan etc.) are valued at last traded price, swap value not modelled.
5. Bonus/split decisions are inferred, not from corporate-action records. Run the sensitivity in §6.3.
6. No index-membership gating: eligibility is liquidity-only (events table unreliable after 2020-07).
7. Price-only, vs a price index (Nifty 500 price excludes ~1.3 pp/yr dividends). Not investment advice.
